# Introduction
An application to drive the big round button, see here for more information:

[https://www.meades.org/misc/big_round_button/big_round_button.html](https://www.meades.org/misc/big_round_button/big_round_button.html)

It is best to open this project in Visual Studio Code using the `Open Workspace from File` option and selecting [`big_round_button.code-workspace`](big_round_button.code-workspace): that way it will open not only the current project but also the components that the project may depend on.
